# The command lines of hostgate.ps1's text gate: each ends before anything is rendered (help, or an error found in the
# options or in building the scene), so they cost no GPU time. Their output and exit code must stay the same as the
# previous step's, apart from the step's allowed differences. One case per line: G for RayTracingGPU, V for
# RayTracingViewer, then the arguments ("double quotes" keep spaces). The programs run from the project's folder.
# None of them may open the viewer's window: every V case must fail before it, or be --help.
